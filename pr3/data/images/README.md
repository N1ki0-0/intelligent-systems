# Фотографии

Фотографии скачиваются автоматически при первом запуске и **не входят** в Git-репозиторий. Их точные имена и страницы Wikimedia Commons указаны в `../aircraft_manifest.csv`.

Для повторного запуска на другом компьютере нужен интернет при скачивании фотографий. Уже скачанные изображения можно скопировать из прошлого проекта сюда.
